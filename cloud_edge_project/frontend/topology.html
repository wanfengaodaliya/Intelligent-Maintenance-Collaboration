📊 页面用途
显示系统各节点的连接关系和运行状态，可以直观看到数据流向和服务健康情况
🔧 怎么看拓扑图
• 绿色流动线 = 数据正常传输中
• 红色线 = 该链路不通
• 节点边框颜色 = 该节点状态
📖 节点说明
• Sender：数据发送端
• edge_01/02：边缘计算节点
• Scheduler：调度器
• Cloud：云端分析
⚠️ 异常排查
如果某节点是红色边框 → 点击下方"边缘节点"页查看详情
如果链路断了 → 说明对应的服务没启动
