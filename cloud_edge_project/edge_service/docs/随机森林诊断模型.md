# 随机森林诊断模型接入说明

`edge_service` 的高采样率数据包流程现在默认在本地加载真实随机森林：

```text
原始数据包
  -> EdgePerception 生成 27 维 PerceptionResult
  -> RandomForestDiagnosticModel
  -> EdgeResult(normal/fault, confidence, risk, model_version)
  -> 原有20包窗口、轴承级和设备级聚合
```

模型制品位于：

```text
edge_service/models/bearing_random_forest/
```

如需从外部只读目录加载同一结构的制品，可设置 `EDGE_RF_MODEL_DIR`。

默认版本为 `bearing-rf-a2-evaluation-v1`。启动时会校验模型、特征契约和
标签映射的 SHA-256；文件缺失、损坏或特征顺序不一致时拒绝加载。

## 当前模型状态

这是使用 Paderborn 数据和冻结 A2 配置训练得到的真实二分类随机森林，不是
Mock，也不是随机输出。但是轴承隔离交叉验证没有达到原定部署门槛，因此清单中
固定记录：

```json
{
  "deployment_status": "evaluation_only",
  "cv_gate_passed": false,
  "locked_test_consumed": false
}
```

本次接入用于完成真实模型技术闭环，不代表模型已经通过工业现场准确率验证。

## 输入输出

输入继续使用 `edge-model-input/1.1` 对应的27维单包特征。模型只输出：

- `normal`：`edge_risk_level=low`
- `fault`：`edge_risk_level=high`

模型不区分内圈和外圈故障，也不生成 `warning`。现有窗口聚合与设备仲裁接口
保持不变。

## 数据集

原始 Paderborn `.mat` 文件、JSONL和Parquet特征均不上传Git。训练人员需要
单独下载数据，并按 `model_training/bearing_random_forest/manifests` 中的清单组织。

## 兼容接口

`POST /edge/packets` 对应的运行时链路使用真实随机森林。旧的同步演示入口
`POST /edge/infer` 仍保留其简化输入合同，并明确标记为 legacy rule；它不应被
当作高采样率生产诊断入口。
